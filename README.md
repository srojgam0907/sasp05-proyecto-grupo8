# AparcaSmart

## Aparca fácil y rápido

**AparcaSmart** es una aplicación diseñada para ayudar a los conductores a encontrar plazas de aparcamiento de forma rápida y sencilla.  
La aplicación muestra en un mapa las plazas disponibles en tiempo real cerca de la ubicación del usuario, incluyendo:

- Plazas libres en la calle
- Parkings gratuitos cercanos
- Plazas para personas con movilidad reducida

El objetivo de AparcaSmart es **reducir el tiempo que los conductores pasan buscando aparcamiento**, disminuir la **contaminación generada por vueltas innecesarias** y mejorar la **accesibilidad urbana**.
